# Proyecto Java: Interfaces y Manejo de Excepciones

Proyecto desarrollado para **Programación 2 (UTN)**, enfocado en el uso profesional de **interfaces**, **herencia múltiple**, **métodos default**, **excepciones personalizadas**, y **manejo robusto de errores** mediante `try-catch`, `throw`, `throws` y validaciones.

---

## 🚀 Tecnologías utilizadas
- Java 17  
- Programación Orientada a Objetos  
- Interfaces y herencia múltiple  
- Excepciones personalizadas  
- Validaciones con clases auxiliares  

---

## 📌 Funcionalidades principales

### ✔️ Implementación de Interfaces
- Creación de interfaces base y derivadas  
- Herencia múltiple entre interfaces  
- Métodos abstractos y métodos `default`  
- Implementación en clases concretas  

### ✔️ Manejo de Excepciones
- Uso de `try-catch-finally`  
- Manejo de múltiples excepciones (`multicatch`)  
- Uso de `throw` y `throws`  
- Creación de excepciones personalizadas  
- Validaciones centralizadas con clase `Validador`
